Application architecture · endpoint map

Asset Manager API endpoints

Browser client reaches public, search, ingestion, media, and admin endpoint families. Search and ingestion share model embedding plus Qdrant vector storage.

Endpoint families

Public application API

  • GET /health checks service dependencies.
  • POST /v1/search embeds query then searches vectors.
  • POST /v1/file-embeddings validates direct uploads and indexes files.
  • GET /v1/storage/{provider}/{id}/thumbnail returns validated provider thumbnail.

Admin family

Session-protected operations

  • POST /auth/login sets secure strict session cookie.
  • /admin/sync/* triggers, streams, stops, and reports synchronization.
  • Provider refresh, item inspection, reindex, and Qdrant-point deletion sit under admin controls.

Shared core

Search and ingestion

Both flows use ingestion service. Model endpoint creates embeddings. Qdrant stores and retrieves vector records.
